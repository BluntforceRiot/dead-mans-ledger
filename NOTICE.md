# Notice

Dead Man's Ledger: The Money Engine is an original static browser game submission build.

No Google Maps screenshots are used.

No copyrighted commercial game assets are used.

## Geodata

The base U.S. map is generated from open geodata:

- `us-atlas`, ISC license, derived from U.S. Census Bureau cartographic boundary shapefiles.
- Natural Earth river centerlines, public domain.

## Libraries

Runtime and build tooling include:

- Vite.
- TypeScript.
- d3-geo.
- topojson-client.
- sharp.
- Playwright as a dev-only screenshot capture tool.

See package metadata and dependency licenses for full library terms.
