PROJECT: Dead Man’s Ledger: The Money Engine

Theme:
Summer into AI Week 2: Independence Engines

Core thesis:
The money provided independence. The route was the engine.

Project concept:
Build a beautiful clickable HD board-game strategy sim about moving currency through dangerous American frontier routes. The player manages shipments, routes, scouts, guards, repairs, telegraph intel, decoys, insurance, interest/credit pressure, reputation, trust, weather, and route hazards. The goal is a high score and survival across repeated journeys.

Very important:
Do not push anything until explicitly approved.

Critical direction:
Do not use AI-generated map images for geography.
Do not use Google Maps screenshots as game assets.
Do not bake city positions and route labels into a generated fantasy map.
The hardest part so far has been keeping U.S. geography and city positions accurate, so build the map from real geodata and coordinates.

Use AI-generated art only for decoration:

* gold logo
* UI panels
* parchment textures
* ledger cards
* tokens
* event vignettes
* icons
* title art

Do not use AI-generated art for:

* U.S. coastline
* Great Lakes shape
* Upper Peninsula of Michigan
* city positions
* base geography
* route graph coordinates

Goal for first build:
Do not make a gray-box alpha.
Build the real foundation with the real map pipeline, real clickable route overlay, real game loop skeleton, and polished board-game UI direction. Aim for a 70 percent complete first foundation, even if some art/event variety is still limited.

Architecture:
Use Vite + TypeScript.
Prefer SVG/canvas overlay for route/node interactions.
The base map should be an accurate 16:9 HD/4K-style U.S. board map.
The game overlay should draw nodes and routes dynamically from data.

Data source requirements:
Use real geodata for map boundaries, coastline, Great Lakes, rivers, and terrain.
Preferred sources:

* Natural Earth public-domain vector/raster data
* U.S. Census TIGER/Line or cartographic boundary data
* Other clearly licensed open geodata only if needed

Map projection:
Use a fixed projection suitable for the contiguous United States, such as Albers USA or Lambert Conformal Conic.
Create a deterministic projection helper so every node is placed from lat/lon, not hand-dragged or guessed.

Deliverable 3: Route data

Create:

* `src/data/routes.ts`

Each route should include:

* id
* from node id
* to node id
* route type: rail, stage, branch, river, sea optional
* biome: northern, mountain, plains, desert, river, forest, gulf, eastern
* base risk
* distance tier
* payout multiplier
* express boolean
* tags for likely hazards

The route graph should support:

* stable node geography
* route availability randomized per run
* long-haul express routes that skip one or two “waves” of nodes
* normal routes that move one node/region at a time
* visible map from the beginning
* hidden route danger
* 30 to 50 percent of active routes having some kind of hidden hazard or complication
* route branches generated from data, not baked into the map image

Important design:
The map should feel like a known frontier network with changing opportunities, not a random spaghetti graph. Nodes stay fixed. Some routes vary per run. Express routes appear/disappear or become attractive based on payout/risk.

* Plains corridor: Denver, Cheyenne, North Platte, Omaha, Des Moines, Chicago, St. Louis

Deliverable 5: Core game loop

Implement the first playable single-player loop.

Player fantasy:
You are the express manager. You sit over a frontier map and decide how to move money safely through dangerous routes.

No keyboard gameplay.
This should be almost entirely clickable.

Interaction model:

* click route
* click prep action
* click route to assign action
* click dispatch
* watch map animation
* read result
* continue to next station

Core actions:

* Scout Ahead
* Hire Guards
* Send Repair Crew
* Telegraph Report
* Decoy Strongbox
* Insurance
* Delay One Day
* Borrow Credit / Credit Line

Possible later/emergency action:

* Backroom Loan or Loan Shark, but keep simple in first pass

Core meters:

* Cash
* Score
* Reputation
* Currency Trust
* Outlaw Pressure
* Interest Rate
* Journey Number
* Current Shipment Value

Shipments:

* Federal Notes
* Mine Payroll
* Bank Drafts
* Merchant Credit
* Land Office Documents
* Silver Reserve
* Treasury Packet

Hazards:

* Outlaw Ambush
* Track Cut
* Washed Bridge
* Bad Weather
* Inside Leak
* Rival Company Sabotage
* Telegraph Cut
* False Local Tip
* Repair Crew Ambushed
* Scout Missing
* Clean Passage

Counter relationships:

* Ambush: Scout Ahead, Hire Guards, Decoy Strongbox
* Track Cut: Scout Ahead, Repair Crew, Guarded Repair Crew
* Washed Bridge: Scout Ahead, Delay, Repair Crew
* Weather: Telegraph Report, Delay, alternate route
* Inside Leak: Decoy Strongbox, Telegraph Report, route change
* Rival Sabotage: Guards, Telegraph Report, Scout
* Telegraph Cut: Scout Ahead, Delay
* False Tip: Paid intel should be more reliable than free tip

Counter bonus:
If the player gathers intel, chooses the correct counter, and the counter succeeds, award bonus score and reputation.

Example:
Scout reveals likely ambush.
Player hires guards.
Ambush triggers.
Guards defend shipment.
Award delivery value + danger bonus + counter bonus.

Scoring:
Score should reward:

* delivered value
* distance/risk multiplier
* express route bonus
* correct counter bonus
* unused budget bonus
* trust streak bonus
* journey completion bonus

Score should penalize:

* shipment loss
* reputation damage
* cash debt
* delays
* failed repairs
* uncountered hazards
* interest paid

High score:
Use localStorage high scores.
Goal is score survival, not one fixed ending.
After completing a journey, carry remaining cash forward and start another journey with slightly worse odds and higher payouts.

Journey progression:

* First journey starts approachable.
* Later journeys slightly increase outlaw pressure, route danger, interest rate range, and payout.
* Difficulty should creep within a range, not suddenly spike.

Lose conditions:

* cash below a hard debt limit
* reputation reaches zero
* currency trust reaches zero

Failure screen copy direction:
“FIRED BY THE BOARD”
Payroll failed. Merchants refused paper. The route lost trust. The town went back to dust, favors, and shotguns.

Success/milestone copy:
“ROUTE LEGEND”
The currency arrived. The towns trusted the notes. The engine kept turning.
