PROJECT: Dead Man’s Ledger: The Money Engine v0.3

Goal:
Turn v0.2 from a strong playable prototype into a visually impressive, public-facing Week 2 submission candidate.

Do not push anything until explicitly approved.

Current status:
v0.2 is mechanically and technically healthy:

* geodata-backed U.S. map pipeline preserved
* city nodes projected from data
* routes drawn dynamically from data
* route/prep/dispatch/result loop works
* six-delivery journey segments added
* Route Legend milestone exists
* Local Tip exists
* Borrow Credit and interest pressure exist
* WebAudio cues exist
* typecheck/build/audit/preview pass

Do not regress any of that.

Critical visual standard:
This update must look HD, crisp, modern, and sleek.

Do not interpret “old west,” “ledger,” “frontier,” or “antique map” as permission to make the UI muddy, blurry, cramped, low contrast, or visually dated.

The theme can be historical and western, but the execution should feel like a premium modern browser board game.

Required visual qualities:

* sharp typography
* high-resolution assets
* clean spacing
* readable labels
* strong contrast
* polished hover/focus states
* smooth animations
* crisp SVG/canvas rendering
* deliberate color palette
* no blurry raster UI
* no default browser-looking controls
* no gray-box prototype panels
* no cramped text blocks
* no muddy brown-on-brown readability problems

Visual target:
A user should be able to glance at the first screenshot and immediately think:
“This is polished enough to click.”

Important:
Do not return to AI-generated map geography.
Do not use Google Maps screenshots as assets.
Do not bake city positions or routes into a fantasy map.
Keep the map data-driven.
Only use generated/illustrated art for UI dressing, tokens, logo, event vignettes, and texture.

Priority 1: Make the map feel like the main board

The current map is accurate and functional, but it still feels too much like a small map inside a dark app panel.

Improve the gameplay screen so the map feels like the central physical game board.

Requirements:

* Make the map visually larger or more dominant where possible.
* Reduce the feeling of empty dark space around the map.
* Make the central board frame feel intentional and premium.
* Add a stronger board-table feel: dark wood, brass edge, subtle cloth/leather desk surface, or polished ledger table.
* Preserve side panels, but make them feel like physical ledger cards attached to the board.
* The map should feel like the “artifact,” not a thumbnail.

Priority 2: Make the title screen look like a real game

The title screen is clean, but it needs more identity.

Improve:

* gold logo treatment
* strongbox/ledger/railroad identity
* subtitle presentation
* background atmosphere
* button polish

Title:
Dead Man’s Ledger: The Money Engine

Subtitle:
The money provided independence. The route was the engine.

The title should feel premium, dangerous, financial, and frontier. It should not feel like plain text in a box.

Priority 3: Upgrade the map styling without breaking accuracy

Keep the geodata pipeline.

Polish:

* state boundary visibility should be greatly reduced or blended into parchment texture
* add subtle terrain relief / engraved-map texture
* Great Plains should feel open and readable
* rivers should be visible but not overpowering
* Great Lakes should stay accurate
* Upper Peninsula and Sault Ste. Marie geography must remain accurate
* city labels should remain readable
* Northeast label density should be improved
* route lines should be clear and attractive

Do not over-brown the map. It should be antique, but still crisp.

Priority 4: Improve route readability and route drama

The route overlay is functional. Make it feel like a board-game route network.

Improve:

* active route glow
* selected route highlight
* express route styling
* rail/stage/branch/river visual differences
* route hover feedback
* route assignment badges
* route selected card

Add stronger visual language:

* rail routes could have dark ties/iron styling
* stage routes could be dotted brass/cream
* express routes could have gold streaking or double-line treatment
* dangerous/rumored routes could get subtle warning marks only after intel reveals them
* assigned prep badges should be visually obvious but not cluttered

Priority 5: Upgrade tokens and dispatch animation

The dispatch should feel satisfying.

Improve:

* moving token visibility
* train/stagecoach/strongbox token style
* dispatch route glow while moving
* small dust/smoke/spark effect
* arrival pulse
* failure shake if shipment fails
* success glint if shipment arrives

Keep it lightweight. Use CSS/SVG/canvas. No video files required.

Priority 7: Improve action panel readability

The preparation panel is improved but still dense.

Improve:

The player should instantly understand:

3. dispatch
